# Pan Bot v1.1.0

Fecha: 2026-11-23

Esta versión amplía Pan Bot con cuatro sistemas por servidor, sin quitar ninguna funcionalidad existente y sin reintroducir música ni Lavalink.

## Novedades

- **Roles automáticos:** roles de entrada múltiples (bots excluidos por defecto), poda de roles borrados, comprobación de jerarquía/permisos y paneles persistentes de autoselección con botones, límites y etiquetas configurables.
- **Estadísticas del servidor:** miembros/humanos/bots en vivo, entradas, salidas y mensajes históricos, actividad diaria/semanal en UTC y canales contador con throttling.
- **Sugerencias:** formulario modal, ID único, votos 👍/👎 cambiables o eliminables, estados de staff, respuestas y etiquetas personalizadas.
- **AutoMod avanzado:** spam, mensajes idénticos, menciones, invitaciones, enlaces, palabras literales y caracteres repetidos, con exenciones y acciones configurables. Reglas nativas de Discord opcionales sin duplicar acciones.

Guías detalladas: [autoroles](../features/autoroles.md), [statistics](../features/statistics.md), [suggestions](../features/suggestions.md), [automod](../features/automod.md).

## Nuevos comandos

| Categoría         | Comandos                                                                                           |
| ----------------- | -------------------------------------------------------------------------------------------------- |
| Roles automáticos | `/autorole setup\|add\|remove\|list\|disable\|panel-create\|panel-edit\|panel-delete`              |
| Estadísticas      | `/stats members\|activity\|setup\|channels\|disable`                                               |
| Sugerencias       | `/suggest`, `/suggestions setup\|config\|view\|status\|disable`                                    |
| AutoMod           | `/automod setup\|status\|enable\|disable\|spam\|words\|links\|invites\|mentions\|exemptions\|logs` |

> Discord no permite mezclar subcomandos y grupos de subcomandos en el mismo nivel. Las acciones de panel se exponen como `panel-create`, `panel-edit` y `panel-delete` en lugar de `/autorole panel …`.

El total de comandos pasa de **19 a 24**; el de eventos, de **14 a 15** (se añade `messageCreate` para AutoMod y actividad). `/help` muestra las cuatro categorías nuevas.

## Cambios en la base de datos

Migración aditiva **`003_autoroles_statistics_suggestions_automod`**, sin tocar las SQL ni los IDs de `001`/`002`:

- Autoroles: `autorole_settings`, `autorole_roles`, `role_panels`, `role_panel_roles`.
- Estadísticas: `guild_statistics`, `stats_daily`, `stat_channels`.
- Sugerencias: `suggestion_settings`, `suggestion_statuses`, `suggestions`, `suggestion_votes`.
- AutoMod: `automod_settings`, `automod_words`, `automod_exemptions`, `automod_incidents`.

Se conservan `guild_settings`, `warnings`, `tickets`, `ticket_participants`, `log_settings` y cualquier tabla musical heredada. No se eliminan ni reinician datos. Se añaden índices, claves primarias compuestas y foreign keys con `ON DELETE CASCADE`; todas las consultas usan parámetros ligados.

## Permisos y configuración

- Quien configura los cuatro sistemas necesita `Manage Guild`.
- El bot necesita `Manage Roles` (autoroles), `Manage Channels` (contadores), `Manage Messages`/`Moderate Members` (AutoMod) y `Manage Guild` para reglas nativas.
- Se mantienen los intents `Guilds`, `Guild Members`, `Guild Messages` y `Message Content`. No se añade ningún intent de voz.
- AutoMod tiene valores **permisivos por defecto**: filtros desactivados y `timeout_minutes = 0`; el silencio y las reglas nativas son opt-in.
- Ejemplo de arranque:

```text
/autorole setup bots:false
/autorole add rol:@Miembro
/autorole panel-create canal:#roles titulo:"Elige tus roles" limite:2
/stats setup canal:"Contador" metrica:members
/suggestions setup canal:#sugerencias staff:@Staff
/automod setup nativo:false eliminar:true advertir:true repetidos:false silenciar:0 registrar:true
/automod spam ventana:10 max_mensajes:6 identicos:true
```

## Correcciones y limitaciones

- Los `customId` de paneles y votos se analizan de forma central y toleran mensajes/configuraciones antiguos o mal formados.
- Los fallos de Discord (canal borrado, falta de permisos, DMs cerrados) se registran y no detienen otros sistemas.
- El historial de AutoMod en memoria se pierde al reiniciar; los contadores de estadísticas sí persisten.
- Las reglas nativas se emparejan por nombre: cambiar umbrales no reescribe automáticamente la regla en Discord.
- No se almacena contenido de mensajes en estadísticas ni incidencias de AutoMod.
- No se reintrodujeron dependencias, comandos ni intents de música/voz.
